# Feed the Blob – rules for every agent working in this repo

Two Claude agents build this game, each in a different account. They never talk directly. They talk only through handover files in `handover/`. Read this file and the newest handover before you touch anything.

Repo: https://github.com/Rick7O7/Feed-The-Blob (branch `main`).

`index.html` in the repo root is generated by `node build.mjs` (copy of `dist/index.html`). Never edit it by hand: change `src/` and rebuild, or your change is lost on the next build.

## Start of every session

1. `git pull`
2. Read `handover/README.md`, then the newest file in `handover/` (highest number).
3. If that handover is addressed to you and lists open tasks, do those first. If it says the other agent is still working (`Status: in progress`), do not edit the files it lists.

## End of every session

1. Build and run the tests (below). Do not hand over red tests unless the handover says so and why.
2. Write the next handover file (format in `handover/README.md`).
3. Commit everything in one commit with the message `handover NNN: <one line>` and push.

Editing the other agent's files is allowed for small fixes. Say so in the handover, with file and reason. Bigger changes: ask in the handover and wait.

## Build and test

```
node build.mjs                      # builds dist/index.html (test), dist/portal-basic, dist/portal-full
python3 test/play_test.py flows     # click-through: controls, shop, ads, KO, rebirth, save
python3 test/raid_test.py unit      # raids
python3 test/boss_test.py           # boss
python3 test/critter_test.py        # critters: hatch, steal, save, 15-min pacing
python3 test/rivals_test.py         # tumble knockback, bouncy loot, rival names/skins/hats, ranking
python3 test/admin_test.py          # admin menu, needs admin/pass.txt
```

Setup once: Node 18 or newer, Python 3.10 or newer, then `python3 -m venv .venv`, `.venv/bin/pip install -r requirements-test.txt` and `.venv/bin/python -m playwright install chromium` (then run tests with `.venv/bin/python`).
Tests use Playwright's own Chromium. To use an installed browser instead: `FB_CHROME=/usr/bin/chromium python3 test/...`.
Agents without a shell (claude.ai chat) cannot run tests: say so in the handover, the other agent runs them.

Business context, rules from the owner and legal notes: `docs/BRIEF.md`. Read it once.

## Hard rules

- `admin/pass.txt` never goes into git. Get the passphrase from the humans. Without it the build skips the admin menu, that is fine.
- Portal builds must not contain the admin menu or the test harness `__fb`. `build.mjs` checks this and fails otherwise. Do not weaken that check.
- Ads follow the CrazyGames rules: break ads only at natural pauses and at most every 3 minutes, rewarded ads only on request and never on the running game screen, every rewarded ad has a gem alternative.
- No real-money purchases, no paid random boxes, no copyrighted characters or brands.
- Vanilla JS and Canvas 2D, one HTML file per build, no external assets.
